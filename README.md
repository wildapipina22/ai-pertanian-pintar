# ai-pertanian-pintar
# AI Sistem Pakar Pertanian 🌾

Proyek ini adalah sistem AI sederhana yang dirancang untuk membantu petani 
mendiagnosis kesehatan tanaman melalui analisis teks atau data sensor.

### Fitur:
- Diagnosa penyakit berdasarkan gejala.
- Rekomendasi penggunaan pupuk.
- Prediksi waktu panen.

### Teknologi:
- Python (Logic & Processing)
- Dataset Gejala Tanaman
